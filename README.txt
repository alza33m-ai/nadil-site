موقع نادل: طريقة الرفع على السيرفر (Coolify)
=============================================

الملفات:
- index.html     صفحة الموقع كاملة
- server.js      خادم بسيط يعرض الموقع ويشغّل المساعد الذكي
- package.json   تعريف التشغيل (node server.js)

قبل الرفع، افتح index.html وعدّل الإعدادات في أول السكربت (ابحث عن «إعدادات نادل»):
  whatsapp: "9665XXXXXXXX"
  email:    "hello@nadil.sa"

الرفع على Coolify:
1. ارفع المجلد إلى مستودع GitHub خاص.
2. في Coolify: New Resource ← Application ← اختر المستودع ← Build Pack: Nixpacks.
3. Port: 3000
4. Environment Variables:
     ANTHROPIC_API_KEY = مفتاحك من console.anthropic.com
5. Domain: https://nadil.sa  ثم Deploy.

بدون مفتاح API الموقع يشتغل عادي، والمساعد يرد بإجابات جاهزة عن الأسعار والمزايا.
المساعد عليه حد ٢٠ سؤال لكل زائر كل ١٠ دقائق عشان ما تزيد التكلفة.

جوّ (شاشات المقهى)
==================
- لوحة التحكم:  https://<موقعك>/jaww/?v=<رمز-المقهى>#admin
- رمز سري لكل مقهى في Coolify:  ADMIN_PINS = {"jalsa":"4821","rwh-smhan":"7310"}
- شاشات كثيرة: من بطاقة «الشاشات» أضف شاشة أو عدة شاشات مرة وحدة.
  كل شاشة: اسم + وش تعرض (المنيو والمباريات / المنيو بس / ليلة المباراة / تلقائي) + أقسام المنيو اللي تظهر فيها.
- ربط تلفزيون: افتح على التلفزيون  https://<موقعك>/jaww/#tv  يطلع رمز من ٤ حروف،
  اكتبه في لوحة التحكم عند الشاشة واضغط «اربط تلفزيون». التلفزيون يتذكر شاشته بعدها.
- حالة كل شاشة (متصلة / آخر ظهور) تظهر في لوحة التحكم.
- العروض لمنيو الطاولات:  https://<موقعك>/<المطعم>/admin.html  وتنحفظ في مجلد data على السيرفر.

لوحة المطعم (العروض + الأصناف + التقرير)
========================================
- الرابط:  https://<موقعك>/<المطعم>/admin.html   والرمز من ADMIN_PINS
- العروض: عرض على صنف أو إعلان عام، بالأيام والساعات.
- الأصناف: صاحب المطعم يغيّر السعر، ويطفي الصنف لما يخلص («خلص اليوم»)، ويضيف صنف أو قسم.
  التعديلات تنحفظ في data/menu-<المطعم>.json فوق data.js. زر «رجّع المنيو الأصلي» يمسحها.
- التقرير: فتح المنيو، الطلبات الجاهزة، متوسط الطلب، التقييم، أوقات الزحمة، الأكثر مشاهدة،
  الطاولات، ملاحظات الزبائن. زر يرسله على الواتساب جاهز.
  الإحصائيات تتجمع تلقائياً في data/stats-<المطعم>.json (بدون أي بيانات شخصية).
- data.js: offersStore: {type:"auto"} = يستخدم الخادم إذا موجود، وإلا نسخة تجريبية على الجهاز.

جوّ: مسابقة توقّع النتيجة
=========================
- من لوحة جوّ ← «مسابقة توقّع النتيجة»: شغّلها، اختر المباراة، واكتب الجائزة.
- يطلع على الشاشة كود QR. الزبون يمسحه ويفتح  /jaww/predict.html?v=<المقهى>  ويكتب اسمه وتوقّعه.
- التوقعات تنقفل مع بداية المباراة. بعدها اكتب النتيجة واضغط «أعلن الفايز» ويطلع الاسم على كل الشاشات.
  لو ما أحد جابها بالضبط، يطلع أقرب توقّع (نفس الفايز بأقل فرق أهداف).
- التوقعات في data/predict-<المقهى>.json. توقّع واحد لكل جوال، ويقدر يعدّله قبل المباراة.
